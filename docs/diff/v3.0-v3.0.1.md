# Differences between v3.0.1 and v3.0

- Fix typos in property and vocabulary entry names
- Reintroduced `adler32`, the Adler-32 checksum, to `Core/HashAlgorithm`,
  previously available in SPDX 2.3
- Miscellaneous bug fixes and non-breaking improvements as reported in the
  change logs and as issues on the spdx-spec and spdx-3-model GitHub
  repositories:
  [spdx-spec change log][spec-log], [spdx-3-model change log][model-log]
