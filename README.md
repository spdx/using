# Using SPDX

**Source for the "Using SPDX" website at <https://spdx.github.io/using/>.**

- The website provides information on how to use the
  [System Package Data Exchange / Software Package Data Exchange (SPDX)
  specifications](https://spdx.org/specifications/).
- It is is not part of the SPDX specification
  and is for informational purposes only.

## Contributing

- Contributions are welcome!
- Types of contributions include, but are not limited to:
  - New guides and tutorials on using SPDX.
  - Improvements to existing documentation.
  - Mappings between SPDX and other standards.
  - Examples of SPDX usage in various tools and workflows.
  - Examples of SPDX usage in specific programming languages.
  - Examples of SPDX usage in non-SBOM contexts.
- Open [an issue](https://github.com/spdx/using/issues)
  or [a pull request](https://github.com/spdx/using/pulls)
  to suggest changes and additions.
- Website content is in the [docs/](./docs) directory.
  Images and diagrams are in the [docs/images/](./docs/images) directory.
- [bin/check-examples.sh](./bin/check-examples.sh) script
  can be used to validate SPDX 3 JSON snippets in the documentation
  (requires GNU awk; macOS users may need to use `gawk` instead of the default
  `awk`).

## Website generation

- The website is generated by [MkDocs](https://www.mkdocs.org/)
  from the content in [docs/](./docs) directory, using the
  [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) theme.
- To build the website locally, install MkDocs, the Material theme, and other
  dependencies by running:
  
  ```shell
  pip install -r requirements.txt
  ```

  Then build the site by running:
  
  ```shell
  mkdocs build
  ```

- The configuration for MkDocs is in [mkdocs.yml](./mkdocs.yml).
